# 字形設計與校樣

## 訂出可以重用的筆畫規則

先畫基線（baseline）、小寫高度（x-height）、大寫高度（cap height）、上伸部和下伸部的參考線。在同一行畫 `H O n o p e`，標出直幹（stem）、弧腹（bowl）、字腔（counter）、開口（aperture）及收筆（terminal）。挑出能在兩三個字上示範的特徵寫入設計規則，再記下哪些筆畫需要逐字調整。

| 想決定的事 | 怎樣試 |
| --- | --- |
| 比例與可辨識度 | 用 `hn po` 比較小寫高度與上、下伸部。在預定距離縮看 `c e o`，確認開口仍清楚。若採用較大的 x-height，保留足夠長度讓 `h/n` 及 `p/o` 易於辨認。 |
| 筆勢與風格 | 手繪時保留筆尖角度與粗幼轉折的線索。比較兩款參照字的 `o e a g`，看圓弧的粗細軸向、橫畫方向、開口和單／雙層結構。用這些可指出的位置描述 serif、sans serif、人文或幾何的選擇。 |
| 部件如何擴展 | 用 `n` 的肩部試 `h m u`，用 `o` 的弧線試 `b d p q`，用 `A V` 試 `W Y`。每次衍生後重看接點和重心。兩個略收窄的 `n` 可作為 `m` 的起點，`w` 也可這樣從 `v` 試起。 |
| 數字和標點 | 決定數字是否齊高、是否隨文字有升降，按用途在班次、票價或日期中試排。用字體原有的筆端、粗幼與留白畫標點，逐個位置對照模板，包括形似的引號、連字號或其他符號。 |

## 由看見的問題決定改哪一筆

| 校樣上的現象 | 可比較的修法 | 重驗 |
| --- | --- | --- |
| 與平頂字等高的圓字看似矮了一截 | 讓 `O/o` 的弧頂、弧底略越過相應參考線（overshoot），尖頂另行判斷。講義示範方形高 100、圓形高 105，圓形上下各越出 2.5 單位。這是理解錯視的幾何示例，實際幅度按字重、弧度與顯示尺寸選。 | 同基線並排 `HOHO`、`nonono` 和 `HAH`，在海報及縮小尺寸各看一次。 |
| 橫畫顯重，圓弧顯弱 | 在 `E/H` 試收幼橫畫，在 `O` 試減薄弧頂與弧底、略加厚兩側。細線或方圓造型另做一版比較。 | 遮掉輔助線，看 `HOEH` 的黑度，再與小寫一同行排。 |
| `p` 的字幹接弧處積黑，或 `n` 的肩部像扭低了 | 在 `p` 試打開接點外側負空間，微調字腔及下方入筆粗幼。在 `n` 試把弧線接到右直幹的位置提高。從 `p` 衍生 `d` 時重畫弧的受力方向。 | 同尺寸並列 `pdpd`、`nhun` 的前後版本，再縮小看積黑是否消散。 |
| 字的上下重心失衡 | 在 `H/E` 試把中橫略提，在 `B/S/8` 試縮小上半部。尖角過長時可截平或磨圓，保留原有的筆端語言。 | 用 `HEB8S` 先看輪廓，再看上下白位。 |
| 同族字放在一起節奏忽緊忽鬆 | 比較 `n o d p` 的字腔寬度。檢查 `c e a` 的收筆角度、`i/j` 的點和字幹之間的視覺關係。帶襯線的設計可試縮短內側襯線，為字腔留白。 | 把修改放回詞內，查看 `minimum`、`open`、`decision` 的整行灰度。 |

## 從 Illustrator 到 Fontself

1. 在 Illustrator 保留手稿參照和可編輯向量稿。用少量可控制的錨點描弧，在平滑轉折處檢查切線。放大看折點，縮小看整個字。保留字腔鏤空，把 `i` 的點和字幹、冒號的兩點等多部件合為可指派給同一字元的圖形。
2. 依模板的大小寫、數字、標點分批送入 Fontself。對準基線並核對每個實際 Unicode 字元與圖形的對應，尤其是 `O/0`、`I/l/1`、左右引號。用字體名稱及版本識別每次匯出。
3. **先校兩側留白（sidebearings）。** 用 `nnonn`、`HHOHH` 或 `HOHO` 建立直邊與圓邊的基準，再把待測字夾在已定的字中，例如 `nnann`、`HHVHH`。同一側在多種組合都太鬆時先看該側的留白。
4. **再校成對字距（kerning）。** 基本留白順眼後，用 `AVATAR`、`To`、`Wa` 看特定組合。記下改過的字對，再把它放進完整詞測一次。Tracking 改變整段字距，leading 改變行距，兩者留待實際排版時處理。

## 字檔驗證

從模板抄出實際字元，儲存為 UTF-8 純文字檔。可將字母連續寫在一行，用換行或空白分組。要列入空格本身請寫 `U+0020`，其餘難以辨讀的字元也可用獨立的 `U+XXXX` 表示。簡短格式示例為 `AB ab 01 ? U+0020`。只放模板字元，保留直引號與彎引號的區別。

在技能目錄使用 Python 3 執行[字集檢查工具](../scripts/check_charset.py)。若此 Python 環境缺少 fontTools，可用 `python3 -m pip install fonttools` 安裝。將下列兩個檔名換成實際路徑。

```sh
python3 scripts/check_charset.py MyDisplay.otf fontself-charset.txt --assignment-3
```

作業模式先檢查清單有 104 個不同字元及完整 A–Z、a–z、0–9，再核對字檔的 Unicode 映射並列出缺字。其他專案可省略 `--assignment-3`，用自己的清單。補充字元可以保留。模板尚未取得時，只就已知字元報告進度。

最後在可選用這一版字檔的另一個應用程式中，用它實際輸入整套模板及一行應用文字。檢查空白、錯形、替代字體、相碰或裁切，再試 `rn / m`、`Il1 / O0` 和一組帶標點的數字。映射檢查、畫面校樣與實體印樣分別記錄結果，例如「104/104 有映射，實字測試發現右引號畫反」。

字形例子取自《35 Tips on Designing Glyphs》第 4–37、41–53、59–76 頁及《Type Design Optical Type》（內題 *Optical illusions in type geometry*）第 3–11、13–37 頁。結構與排字可對照《Type Anatomy》第 2–15、32–40、56–61、75 頁及《Typeface Design Week 1》第 13、23–40 頁。頁碼依 PDF 頁序，校樣字串與命令為實作示例。
